App control

API KEYS

Sirf aap dekh/badal sakte ho. Ek baar SAVE karne ke baad keys yahan har baar apne aap bhari milengi, dobara copy nahi karni. Key se provider apne aap pehchana jaata hai (AQ. = Gemini, sk-or- = OpenRouter, gsk_ = Groq, csk- = Cerebras, sk- = DeepSeek/OpenAI).
1. MUKHYA API
Sabse pehle yahi chalegi. OFF karoge to seedha backup se chalega.
2. BACKUP API
Mukhya thake ya band ho to ye line se chalengi. "+" dabao to ek aur dabba judega, ✕ dabao to wo hat jaayegi.
3. ALAG ALAG KAAM KE LIYE ALAG API
Abhi OFF rakho. ON karoge to neeche coding, photo aur live ke dabbe khulenge. Jis kaam ka tick ON ho aur key bhari ho, wahi key us kaam mein chalegi; warna upar wali normal keys hi chalengi.
CODING / APP / GAME
OpenRouter, Groq, Cerebras, DeepSeek ya OpenAI ki key (Gemini nahi).
PHOTO banana / edit karna
Gemini key (alag project ki). OFF ya khaali ho to AI bolega ki photo banana/edit abhi uplabdh nahi, baaki normal chat chalti rahegi.
LIVE AWAAZ (orb)
Gemini key (alag project ki).

AI ka brain (nayi baatein sikhao)

Jo yahan likhoge AI use sach maanega aur jawab mein kaam lega (taaza 3500 akshar tak). Aap chat mein bhi bol sakte ho: "yaad rakho ...".

Locked users (malik ko gaali dene wale)

AI ya app ne jise lock kiya wo yahan dikhega, uski maafi ke saath. "MAAF KIYA" dabane par uska app khul jaata hai. Haath se lock sirf pakke (verified) Google login wale par chalta hai.

Mere baare mein jaankari (AI isi se batata hai)

Email yahan mat likho. Likhoge bhi to app use hata deta hai aur AI kabhi email nahi batayega.

Malik ki pehchaan (owner email)

AI isi se pehchanta hai ki kaun malik hai. Email app ya database mein seedha nahi rakha jaata, sirf uska SHA-256 hash save hota hai, isliye koi nahi padh sakta. Malik wahi maana jayega jo is email se pakke (verified) Google login se aaya ho.
